# Текущее состояние dsh-plugin-polza

Обновлено 22 ноября 2026, MSK.

## Обновление и первое подключение Polza

- База задачи `867647a`. Опубликованный пакет `0.3.4` включает PR #10, #11 и #12.
- Выпуск `0.3.4` обновляет список моделей после авторизации, но сохраняет выбранный провайдер. В изолированном Harness 0.2.2-rc.1 это проверено на тестовых учётках DeepSeek и Polza.
- Локальный кандидат проверяет стабильные совместимые версии npm при запуске и передаёт установку менеджеру пакетов Harness. Переключатель в **Настройки → Польза** включён по умолчанию. Установки из Git, архивов и локальных каталогов обновляются вручную.
- Блок обновлений расположен в конце настроек **Польза**, после моделей и остальных параметров. Кнопка **Проверить обновления** работает и с выключенным автообновлением. Проверены поиск доступной версии для npm-установки без изменения установленной версии и получение опубликованной версии для локальной сборки.
- Polza регистрирует ссылку на свой ключ в каталоге провайдеров Harness, который desktop читает при запуске для определения, подключён ли провайдер.
- В изолированном Windows Desktop профиль с одним сохранённым ключом Polza открыл рабочее окно после холодного запуска. В открытом окне проверена кнопка обновления и включённая по умолчанию галочка.
- При первом подключении Polza заменяет стандартную модель DeepSeek первой доступной моделью Polza с поддержкой инструментов. Выбор записывается в профиль Harness, оба подключения доступны в пикере.
- В изолированном Harness Web 0.2.2-rc.1 на Windows проверены сохранение переключателя, OAuth с локальным обменом кода, обновление открытого черновика и нового чата, сохранение модели и истории начатого чата DeepSeek, ручное переключение обратно. Платные запросы не отправлялись.
- В изолированных профилях штатный менеджер обновил npm-фикстуру с кодом кандидата с `0.3.3` до настоящей `0.3.4`. С отключённым автообновлением и на исходной `0.3.3` версия сохранилась. Профиль с отключённым HMR сообщил о требуемом перезапуске.
- Локально прошли проверка типов, 19 тестов, сборка и проверка состава npm-пакета. Первый выпуск с автообновлением пользователям прежних выпусков потребуется установить вручную.

## Выбор провайдера модели

- Исходная версия отката: `cfdf045` (`0.3.0`).
- В меню пикера для моделей Polza пункт «Провайдер» расположен между «Моделью» и «Усилием». Список использует те же стили и клавиатурную навигацию, что и «Усилие».
- Список берётся из карточки выбранной модели в каталоге Polza. Выбранные провайдеры поднимаются вверх в порядке нажатия. Приоритет меняется стрелками и сохраняется для каждой модели. Запрос передаёт `provider.order` и `provider.only`. «Авто» снимает все отметки. Старые одиночные настройки читаются как список из одного провайдера.

## Проверки

- Windows, Node 24: `npm run typecheck`, `npm test` (17 тестов), `npm run build`.
- Тест реального PiAiAdapter против локальной SSE-заглушки подтвердил порядок в `provider.order`, ограничение в `provider.only` и отсутствие поля `provider` в режиме «Авто».
- Изолированный Harness 0.2.2-rc.1 в Edge: порядок строк, совпадение стилей с «Усилием», навигация по Escape, списки Claude Sonnet и DeepSeek, выбор по порядку, перестановка стрелками в обе стороны, снятие галочки с возвратом строки на прежнее место, сохранение после перезагрузки и «Авто».
- Для проверки отката платная генерация не использовалась. Подсказка расхода использует существующую приблизительную оценку по тарифу модели из каталога и может отличаться от тарифа выбранного провайдера.

## Совместимость и продолжение

Встроенный пикер Harness 0.2.2-rc.1 не предоставляет слот между моделью и усилием. Поэтому плагин занимает слот пикера компонентом на основе штатной реализации под MIT и использует общий каталог и операции выбора Harness. Сторонние расширения штатного слота подписи модели в этом компоненте не отображаются.

PR #5 влит. Отмена `8f0a78e` возвращает контракт `583bc14`: плагин передаёт упорядоченный список Polza, а шлюз применяет свою маршрутизацию, включая выбор прогретого маршрута. Изменение подготовлено поверх текущего `main`.
